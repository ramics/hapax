# Annotating the residue contigs

Generated by `experiments/report_residue_contig_annotation.py`. Script `cb9ba5c7ec50`. Prodigal in metagenomic mode; Pfam-A at each family's own gathering threshold; cmscan --rfam --cut_ga --nohmmonly, -Z over both piles. Controls are log bins, ratio 1.25 from 200 nt, without replacement. 5 of 5 seeds ran on a dirty tree, so their commit names HEAD; the script hash pins them. The residue pile is deterministic - every contig is annotated and nothing is sampled - so it is computed once and reused by 4 of 5 seeds, which vary only the controls and the shuffle.
